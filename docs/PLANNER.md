# Planner

TraceLens deterministically uses ECR, HBM headroom, rank imbalance, message regime, and tail ratio to
label COMPUTE, COMM_LATENCY, COMM_BANDWIDTH, MEMORY, RANK_IMBALANCED, or MIXED. Thresholds are v1
source-controlled inputs to the freeze manifest.

Guard sees hardware/topology, legitimate microbenchmarks, a baseline profile, and only candidates it
selected. It proposes at most three candidates. Correctness, finite values, memory, tail latency,
and artifact integrity gate eligibility before throughput selection. Characterization and profiling
are included in total tuning cost.
